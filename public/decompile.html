Good to know

  • Up to 60MB per file — enough for most single-DEX APKs.
  • Decompiled output is an approximation — variable names get regenerated, and heavily obfuscated code may come back partial.
  • Only decompile code you have the right to inspect.
  • Runs are saved to History in your browser, same as conversions.
