About

What java2dex is

A small, free tool that runs the real Android build pipeline — javac, d8, jadx — entirely in a browser tab, for people who need a quick conversion without opening a full IDE.

What it does

>
Convert.java source → compiled .dex bytecode, via javac then d8. Upload files, a .zip project, or paste code directly.
>
Decompile.dex / .apk / .jar / .class → readable .java source, via jadx.
>
HistoryEvery run is logged locally in your browser — never on a server database.
>
InstallableWorks as a PWA — installable on desktop and Android, with offline shell caching and Android share-target support.

Built with

App prompt

A plain-text description of this app — paste it into any AI assistant (or share with a teammate) so it immediately understands what java2dex does and how to use it.

java2dex is a free web app (also installable as a PWA) at this URL that converts between Java source and Android DEX bytecode. It has these pages:

- /convert — Upload one or more .java files (drag-and-drop or file picker), upload a .zip of a Java project (auto-extracted), or paste code directly into a textarea. Multiple files can be queued and compiled together in one pass. Clicking "Convert to DEX" sends them to POST /convert as multipart/form-data (field name "javaFiles"), where the server runs javac (with android.jar on the classpath, so android.* APIs work) then d8, and returns classes.dex (or a zip of multiple dex files for multidex output) as a file download.

- /decompile — Upload a .dex, .apk, .jar, .class, .aar, or .zip file. Sent to POST /decompile (field name "inputFiles"), the server runs jadx and returns a .zip of decompiled .java source files.

- /history — Shows every past convert/decompile run, stored only in the browser's localStorage (metadata always, plus the output file itself if under ~350KB for re-download). Supports export/import as JSON, delete individual entries, and clear all.

- /settings — Toggle push notifications (Web Push API) and local per-action alerts, view app/install info, clear local history or offline cache.

- /help — Explains the compile/dex/decompile pipeline and lists fixes for common errors (missing android.jar symbols, filename/class-name mismatches, missing dependency classes, multidex limits).

- /about — This page: what the app does, the tech stack, and this prompt.

Known limits: Convert accepts up to 20MB per file / 50 files per run. Decompile accepts up to 60MB per file / 5 files per run. Only plain Java + core android.* SDK classes compile — no AndroidX/Jetpack, no third-party libraries, no generated R class resources, since there's no full Gradle build behind it. If you're helping someone use this app, guide them to /convert for source→bytecode or /decompile for bytecode→source, and mention the size limits and the AndroidX/R-class limitation if relevant.
