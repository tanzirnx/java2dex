Help

How it works, and what to do when it doesn't

The converter runs the exact same two steps a real Android build runs.

javac

Every .java file in your queue is compiled together in one call, with android.jar on the classpath.

d8

The resulting .class files are converted into one or more .dex files.

Common errors

package android.app does not exist

Your file references Android SDK classes (android.app, android.widget, android.graphics, etc). The converter already puts android.jar on the classpath by default — if you still see this, the class or package name may be misspelled, or you're using an API from a newer platform level than the one bundled (currently android-34).

class X is public, should be declared in a file named X.java

Java requires a public top-level class to be named exactly the same as its file. When pasting code, check the auto-filled filename matches your public class — edit it if the detector picked the wrong name.

cannot find symbol — referencing another class you also wrote

Add every file the code depends on to the same queue before converting. All files in a run are compiled together, so classes in the queue can reference each other, but a class that isn't in the queue won't be found.

d8 ran but produced no .dex output / DEX conversion failed

This usually means the compiled bytecode uses a newer class-file version than d8 expects, or a method/field count limit was hit on a single dex file (rare for small snippets). Try isolating the file that's causing it.

Why can't I run the .dex file here?

d8 only converts bytecode — it doesn't execute it. android.jar contains method stubs (signatures, no real bodies), so code compiles and dexes correctly but isn't runnable outside an actual Android device or emulator. Install the resulting classes.dex into an APK, or use it with your existing build.

Where is my history stored?

In this browser's localStorage only — metadata for every run, plus the output file itself if it's under roughly 350KB. Nothing is uploaded or kept on the server after your download starts. Clearing your browser data or using a different device/browser means a different history.

Is there a size limit?

20MB per file, up to 50 files per run — enough for source files with embedded base64-encoded images or other large string literals.
