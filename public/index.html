Turn .java files into installable DEX bytecode.

Build stages

Same pipeline, every time

01 · Source

Upload .java files or paste code straight into the editor. Multiple files at once, any length.

02 · Compile

javac compiles everything together, with android.jar on the classpath for SDK references.

03 · Dex

d8 converts the .class output into Dalvik bytecode — classes.dex, ready to package.
